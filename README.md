# 🌍 EarthTrend – NASA-Powered Climate Intelligence

### Be An Earth System Trend Detective!

EarthTrend is a climate analysis and visualization platform developed using NASA POWER data. It explores historical temperature and rainfall patterns across three locations in Kerala, India: Kollam, Idukki and Trivandrum.

The project identifies climate trends, detects unusual rainfall patterns, evaluates exploratory climate risk indicators and uses Machine Learning to explore future climate trends.

## 🎯 Project Objectives

- Analyze historical temperature changes.
- Study annual rainfall variations.
- Identify statistically significant climate trends.
- Detect extreme rainfall years.
- Compare climate patterns across different locations.
- Explore future temperature and rainfall predictions.
- Present environmental insights through an interactive dashboard.

## 🛰️ Data Source

**NASA POWER – Prediction Of Worldwide Energy Resources**

Dataset parameters:
- T2M – Temperature at 2 meters.
- PRECTOTCORR – Corrected precipitation.

Study period: 2001–2025.

Study locations:
- Kollam, Kerala
- Idukki, Kerala
- Trivandrum, Kerala

## 🤖 Machine Learning

The project explores Linear Regression and Random Forest models to analyze historical climate data and estimate future climate patterns.

Model performance is evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/Avanthika812/EarthTrend-NASA-Space-Apps.git
```

### 2. Navigate to the project folder

```bash
cd EarthTrend-NASA-Space-Apps
```

### 3. Install dependencies

```bash
pip install pandas numpy matplotlib scipy scikit-learn streamlit requests
```

### 4. Launch the dashboard

```bash
streamlit run app.py
```

The dashboard will open in your browser.

## 🌱 Expected Impact

EarthTrend demonstrates how open NASA Earth science data can be transformed into meaningful climate insights through data analysis, visualization and machine learning.

It aims to make historical climate patterns easier to explore and understand, supporting environmental awareness and further climate research.

## ⚠️ Disclaimer

Climate risk indicators and future predictions are exploratory outputs based on the selected historical datasets. They should not be interpreted as official climate projections or disaster-risk assessments.
